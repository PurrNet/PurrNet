Detailed Description

Modular, GC-free fragmentation layer for transports that don't handle fragmentation natively. Splits outgoing messages into MTU-sized fragments and reassembles incoming fragments.

Hot path (unfragmented messages) produces zero GC allocations. Uses BitPacker pooling for all intermediate buffers.

Header format: Unfragmented: [1 byte: 0x00] [payload] Fragmented: [1 byte: 0x01] [2 bytes: messageId] [1 byte: fragmentIndex] [1 byte: totalFragments] [payload]
