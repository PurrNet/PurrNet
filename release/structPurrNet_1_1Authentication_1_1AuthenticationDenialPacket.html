Detailed Description

Server -> client packet describing why a connection is about to be closed. The client decodes reason via the active AuthenticationLayer.OnDenialReceived override (typed by AuthenticationBehaviour<TRequest,TDenial>) and acks with AuthenticationDenialAck. The server closes the connection on ack OR after the authenticator's timeout, whichever fires first.
