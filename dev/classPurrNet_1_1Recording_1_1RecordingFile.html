Detailed Description

Writes the .purrrec container. Records are framed on the caller's thread; compression and disk writes happen on a background thread so a host does not hitch when a chunk is flushed. On WebGL, which has no C# threads, queued records are encoded by Pump on the main thread (one chunk per call) and a Web Worker compresses and stores them in the browser (IndexedDB); path is then only the recording's name there.
