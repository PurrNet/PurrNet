class  NetworkRecorder
 Records a match to a .purrrec file on the server or host: every spawned network identity's transform, colliders and recorded sync types (SyncVar, SyncList, SyncTimer) per tick, and the players. Add one next to the NetworkManager. Other packages add their data through RecorderExtensions (with PurrDiction: every predicted component's state and input), so a match is one file whatever it is made of. On a client it writes what only that client has (its camera, raw input, UI and anything written through WriteSample<T>) to a part of the recording: a file of the client's own that it uploads itself. class  RecordLocalCamera
 Writes the camera this machine renders with to the "camera" stream. Recorders add one next to themselves unless its camera recording is turned off; add your own to record a specific camera. The pose is taken right before the camera renders, after every script and camera rig has moved it, so it is exactly what the player saw. Without rendering (batchmode) it falls back to the end of LateUpdate. One sample is taken per tick. On a client it goes into the client's own part of the recording, never over the connection. More...
 
class  RecordLocalInput
 Writes what the player's devices did to the "input" stream, one row per tick: pointer movement, scroll, mouse buttons, held keys and the gamepad. Recorders add one next to themselves unless input recording is turned off. A key or button pressed and released between two rows is still in the next row. While a text field has keyboard focus no keys are recorded; the row says the player was typing instead. On a client the rows go into the client's own part of the recording, never over the game's connection. More...
