Detailed Description

Writes what this machine's UI shows to the "ui" stream, as data: every uGUI graphic (Image, RawImage, Text, TextMeshPro) and UI Toolkit element with its rectangle, colours, sprite name, text and control value. A row is written when an element changes, and the whole tree again at the start of every chunk. Recorders add one next to themselves unless their UI recording is turned off.

Changes the UI systems announce (text, colour, sprite, size) are recorded on the tick they happen. Changes they do not announce (an element moved by its transform, faded by a CanvasGroup, restyled in UI Toolkit) are found by going over the elements, as many per tick as checkBudgetMs allows; an element found changing is then looked at every tick until it stops.

Password and PIN fields are never recorded. DontRecordUI keeps a part of the UI out.
