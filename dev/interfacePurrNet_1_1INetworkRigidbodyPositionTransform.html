Detailed Description

Pluggable origin converter for NetworkRigidbodyBase (NetworkRigidbody and NetworkRigidbody2D).

In an origin-shifted world each peer runs with a different local Unity origin, so a raw Vector3 position is meaningless on another peer and loses precision long before a large world reaches the floor of double precision. This converter is invoked only at the wire boundary: outgoing positions are mapped into a shared, peer-agnostic absolute frame (a double3) and incoming absolute positions are mapped back into this peer's Unity world space.

The absolute double3 is what travels on the wire and what the interpolation buffer stores, so a local origin shift needs no extra bookkeeping — the next ToLocal simply reflects the new offset and every buffered snapshot stays correct.

Resolution order on spawn (first non-null wins):

  1. Runtime override set via NetworkRigidbodyBase.SetPositionTransform.
  2. Sibling component implementing this interface on the same GameObject.
  3. Static fallback at NetworkRigidbodyBase.defaultPositionTransform.

When none is installed, positions travel on the wire as the legacy quantized CompressedVector3 in this peer's own Unity world space (byte-identical to prior versions). Only translation is converted; rotation and velocity are origin-invariant.
