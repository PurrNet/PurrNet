Called on the client by AuthModule when a denial packet arrives. The default implementation does nothing; AuthenticationBehaviour<TRequest,TDenial> overrides this to deserialize the reason bytes into TDenial and surface onDeniedByServer. reason is null when the server sent no payload (e.g. built-in deniers like version mismatch / timeout).
