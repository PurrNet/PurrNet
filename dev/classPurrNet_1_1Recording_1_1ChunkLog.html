Detailed Description

A chunk's rows as the recorder wrote them: one append-only log for every stream, so there are no per-stream buffers to size (or grow). Each entry: [slot i32][tick u64, only when the slot has TickFollows] [fixed row][per managed field: i32 length (-1: same as the stream's previous value) and bytes]; an entry without a tick has the previous entry's. A per-tick stream has an entry for its first tick in the chunk and for every tick its row changed; the ticks in between, up to ChunkStream.lastTick, repeat the row before them. Logs are reused; after warming up nothing grows.
