Detailed Description

Something that puts entities into a RecordingSession (predicted objects, network identities). The session asks its sources which scene objects belong to an entity, so their colliders and renderers are recorded with that entity and not as part of the static world. Several sources can share one entity (a GameObject with both a network identity and predicted components): the first creates it, the others attach to it.
