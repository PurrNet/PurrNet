Detailed Description

Records a match to a .purrrec file (see recording/FORMAT.md) on the server or host: every spawned network identity's transform, colliders and recorded sync types (SyncVar, SyncList, SyncTimer) per tick, and the players. Add one next to the NetworkManager. Other packages add their data through RecorderExtensions (with PurrDiction: every predicted component's state and input), so a match is one file whatever it is made of. On clients it forwards their camera and anything written through WriteSample<T>. State that only exists on clients is not recorded.
