Detailed Description

Authentication behaviour with a typed denial payload. On the server, returning success = false from ValidateClientPayload ships the supplied TDenial to the client (via AuthenticationDenialPacket) before the socket closes. On the client, onDeniedByServer fires with the decoded reason so user UI can react.

This is a separate type from AuthenticationBehaviour<T> to preserve the existing contract; pick this overload when you need to surface a structured rejection reason to the client UI.
