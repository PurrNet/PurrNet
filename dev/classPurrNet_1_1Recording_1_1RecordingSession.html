PurrNet.Recording.RecordingSession Class Reference

Writes a match to a self-describing .purrrec file (see recording/FORMAT.md): entities with their transforms, colliders and streams, players, and custom streams such as each player's camera. A recorder owns one and feeds it every tick; RecordingSources say which scene objects belong to which entity. On a client it writes that client's own part of the server's recording (see RecordingSession.Parts); nothing but the server's start and stop announcement travels over the game's connection. Once running it makes no garbage: storage is pooled, metadata is written straight to bytes, and managed fields are read in place. More...

Detailed Description

Writes a match to a self-describing .purrrec file (see recording/FORMAT.md): entities with their transforms, colliders and streams, players, and custom streams such as each player's camera. A recorder owns one and feeds it every tick; RecordingSources say which scene objects belong to which entity. On a client it writes that client's own part of the server's recording (see RecordingSession.Parts); nothing but the server's start and stop announcement travels over the game's connection.
