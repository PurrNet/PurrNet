void RecordEffects (ulong tick)
 Writes what animators, particle systems and audio sources started doing since they were last asked: a row per change, nothing while they carry on. Objects the game created since the last tick are looked at first, then the ones something was called on, then the rest in turn. All of it stops at effectsBudgetMs and continues from there on the next tick; the first two get no more than half of it, so that a busy game cannot keep the rest from ever being asked.
 
void RecordTransformLater (RecordedEntity entity, RecordingSource source, ulong tick)
 Records the entity's pose for this tick like RecordTransform, without the caller needing it back. With many entities the transform is not read here: a job reads all of them at the end of the tick, on other threads, and the rows are written when the next tick begins (with this tick's number, so the file is the same). Whether the entity is visible is still looked up here; only the main thread can.
