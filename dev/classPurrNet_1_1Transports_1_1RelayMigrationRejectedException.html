Detailed Description

The relay refused a host migration request for a reason the caller can act on. Known codes: host_connected (a claim without authorization while the host is still connected; for a lost host the relay has not noticed yet), generation_mismatch (someone else claimed first), invalid_secret (not a secret of the room, or an authorization that was used, expired or issued for another player) and invalid_host_secret.
