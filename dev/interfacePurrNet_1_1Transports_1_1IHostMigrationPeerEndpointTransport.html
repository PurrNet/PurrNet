Detailed Description

Optional transport support for peer-hosted host migration. The healthy host reads every client's route with TryGetPeerMigrationEndpoint and shares it; when the host is lost, the elected client and the others prepare their route with TryPreparePeerMigrationEndpoint before calling NetworkManager.PromoteToServer or NetworkManager.TransferToNewServer.
