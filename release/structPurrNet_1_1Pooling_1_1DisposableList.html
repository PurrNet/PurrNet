 Direct access to the backing list. This hands out mutable access, so if the buffer is shared with a snapshot it is unshared first. Prefer the regular list API for reads; it never forces an unshare. Do not cache the returned reference across a Duplicate() or history save: writes through a cached reference bypass copy-on-write and can corrupt shared snapshots.
