Uploads run only while this game has no network session, one file at a time, so they never compete with match traffic; an upload cut off by a new session is retried later. Detailed Description

Sends finished recordings to the PurrNet recordings service and deletes them once they are sent. Uploads run only while this game has no network session, one file at a time, so they never compete with match traffic; an upload cut off by a new session is retried later. The service answers each file with a short-lived upload URL (the bytes go straight to storage) or with "skip", in which case the file is deleted unsent. Recordings that cannot be sent are kept up to a size cap, oldest deleted first. The settings are remembered, so files left by an earlier session are sent from the next launch on, before any match scene loads. On WebGL the recordings live in the browser (IndexedDB) and the recording worker sends them with the same protocol and rules; the service and its storage must allow the game's origin (CORS).
